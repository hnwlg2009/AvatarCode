## Context

AvatarCode 是一款基于 Electron + React 的 AI 原生代码编辑器。当前界面仅支持英文，需要添加多语言支持以满足中文用户的需求。项目使用 React 18、Zustand 状态管理、Monaco Editor 等技术栈。

## Goals / Non-Goals

**Goals:**
- 实现完整的 i18n 国际化框架
- 支持英文和中文两种语言
- 提供语言切换功能
- 保存用户的语言偏好
- 支持根据系统语言自动检测

**Non-Goals:**
- 暂不支持其他语言（日语、韩语等）
- 暂不支持 RTL（从右到左）语言
- 暂不支持动态加载语言包

## Decisions

### 1. i18n 库选择：react-i18next

**选择**: react-i18next + i18next

**理由**:
- React 生态最成熟的 i18n 方案
- 支持命名空间、复数、上下文等高级功能
- 与 React 深度集成，支持 hooks API
- 社区活跃，文档完善

**备选方案**:
- react-intl: FormatJS 方案，API 较复杂
- 自研方案: 开发成本高，维护困难

### 2. 语言资源结构

**选择**: 按功能模块组织语言资源

```
src/i18n/
├── index.ts              # i18n 配置
├── locales/
│   ├── en/
│   │   ├── common.json   # 通用文本
│   │   ├── editor.json   # 编辑器相关
│   │   ├── settings.json # 设置相关
│   │   └── menu.json     # 菜单相关
│   └── zh/
│       ├── common.json
│       ├── editor.json
│       ├── settings.json
│       └── menu.json
```

**理由**:
- 按功能模块划分，便于维护
- 支持命名空间，按需加载
- 便于团队协作翻译

### 3. 语言切换实现方式

**选择**: Zustand store + localStorage 持久化

**理由**:
- 与现有状态管理方案一致
- 支持实时切换，无需刷新页面
- 持久化用户偏好

### 4. Electron 主进程国际化

**选择**: 使用 electron-i18n 模块

**理由**:
- 主进程和渲染进程独立管理语言资源
- 支持菜单、对话框等原生元素国际化

## Risks / Trade-offs

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 翻译质量 | 用户体验 | 使用专业翻译，社区审核 |
| 性能影响 | 启动速度 | 按需加载语言包 |
| 维护成本 | 开发效率 | 建立翻译规范，自动化工具 |
| 兼容性 | 功能异常 | 充分测试，渐进式迁移 |

## Migration Plan

1. **阶段一**: 搭建 i18n 框架，配置语言资源结构
2. **阶段二**: 提取通用组件文本（按钮、标签等）
3. **阶段三**: 提取功能模块文本（编辑器、设置等）
4. **阶段四**: 实现语言切换 UI
5. **阶段五**: 测试和优化
